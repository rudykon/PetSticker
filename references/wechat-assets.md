# 微信宠物表情包素材规范

## 默认专辑素材规格

| 素材 | 默认数量 | 格式 | 像素尺寸 | 背景要求 | 平台压缩提示 |
|---|---:|---|---:|---|---:|
| 表情图片 | 8–24；完整套默认24 | 静态PNG/JPG；动态GIF | 240×240 | 依设计；宠物贴纸建议真实透明 | 大于500KB可能被压缩 |
| 表情形象头像 | 1 | PNG | 240×240 | 必须真实透明 | 大于500KB可能被压缩 |
| 详情页横幅 | 1 | JPG/JPEG/PNG | 750×400 | 不透明、避免白底 | 大于500KB可能被压缩 |
| 表情封面图 | 1 | PNG | 240×240 | 必须真实透明 | 大于500KB可能被压缩 |
| 聊天页图标 | 1 | PNG | 50×50 | 必须真实透明 | 大于100KB可能被压缩 |
| 赞赏引导图 | 启用时1 | JPG/GIF/PNG | 750×560 | 与表情相关 | 大于500KB可能被压缩 |
| 赞赏致谢图 | 启用时1 | JPG/GIF/PNG | 750×750 | 与表情相关 | 大于500KB可能被压缩 |

平台所说“大于阈值将被压缩”不等于“超过阈值禁止上传”。若用户另有体积上限，按更严格的用户要求导出。

动态 GIF 还必须按用户要求记录并检查帧数、逐帧延时、完整循环时长、循环方式和逐帧透明背景；具体方法见 [animated-stickers.md](animated-stickers.md)。这些动画参数不是平台配套素材尺寸表的一部分，不要从静态表格中推断。

## 内容约束

- 详情页横幅完全不含文字，包括标题、说明、署名和可读名牌；使用无文字项圈或隐藏名牌。
- 横幅避免透明和纯白背景，色调活泼明朗并与专辑主题有关；不得因拉伸、压扁或错误缩放而变形。
- 头像与封面优先使用可辨识的正面半身或全身形象，减少装饰和留白，避免白色描边、锯齿及无必要文字。
- 聊天页图标优先使用正面头部近景；封面和聊天页图标不要出现正方形底板/边框，不同专辑使用不同图案。
- 透明图必须为带 Alpha 的 RGBA/GrayAlpha 文件；角落透明不能单独证明整张没有伪棋盘格，仍需彩底目视检查。
- 主体完整：不得意外裁切耳朵、四肢、爪、尾巴、文字或符号；有意使用头像/胸像时，裁切边界要自然且不出现半截肢体。
- 文字必须与表情语义一致、准确可读，不能遮挡脸、动作或关键配饰。
- 赞赏图只放与宠物/专辑相关的内容。赞赏文案由用户决定，不把示例文案写死为通用规范。

## 推荐 manifest.json

```json
{
  "album_name": "宠物名｜主题",
  "pet_name": "宠物名",
  "expected_stickers": 24,
  "stickers": [
    {"file": "01_example.png", "caption": "示例", "intent": "语义说明"}
  ],
  "assets": {
    "character_avatar": "character_avatar.png",
    "detail_banner": "detail_banner.jpg",
    "album_cover": "album_cover.png",
    "chat_icon": "chat_icon.png",
    "tipping_prompt": "tipping_prompt.jpg",
    "tipping_thanks": "tipping_thanks.jpg"
  }
}
```

manifest 用于逐字核对文案、排序和交付，不代替平台上传表单。

动态专辑可从 `assets/animated_manifest.template.json` 起步，并把实际帧数、延时和循环时长写进清单。

## 标准输出层级

- `references_private/`：用户原始宠物照片和身份锚点，只保存在工作项目中，默认不分享。
- `work/`：高分辨率源、草稿、失败稿和返修稿；不得进入正式 ZIP。
- `release/stickers/`：独立正式表情文件。
- `release/assets/`：平台配套素材。
- `release/manifest.json`：文件、文案、语义和顺序的机器可读清单。
- `release/character_bible.md`：已确认的身份、体型、配饰和禁止项。
- `release/qa_report.md`：自动检查结果、人工逐图审查结论和未能自动证明的事项。

平台上传时只选择对应图片；交付 ZIP 可以包含三份说明文件。除非用户明确授权，不要把私人参考照片放入 ZIP 或公开目录。
